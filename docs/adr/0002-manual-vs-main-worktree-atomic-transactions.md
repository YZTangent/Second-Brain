# 0002: Separate Code/Vault Repositories and `manual` vs `main` Worktree Transactions

Engine source code (`second-brain-v2`) and personal brain content (`<vault-path>`, identified by `.second-brain.json`) live in two separate Git repositories so code changes never share history with personal memory commits. On startup, `braind` accepts a vault path: it opens an existing valid vault, initializes a new vault if the path is missing or empty, and aborts if the directory is non-empty and not a valid Second Brain vault. Inside the vault repository, the root working directory stays checked out on branch `manual` while `main` serves as the canonical ledger (and default branch served to Web UIs, with optional `?branch=main|manual` selection). Every explicit `/remember` call (and daily `synthesizer` batch) executes inside a session-scoped detached Git worktree (`.brain/tx/<tx_id>`) rooted at `main`, commits atomically (`1 /remember = 1 commit`), advances `main` without checked-out branch conflicts, and merges `main` into `manual`.
